# Manor bathroom

SPDX-License-Identifier: CC-BY-NC-SA-4.0

The north-east passage from the Rotunda, beside the Card Room, leads into a marble bathroom. It has a pedestal sink, decorative framed mirror, towels, a privacy screen and a toilet with a freestanding brass toilet-paper spool stand beside it.

PNG art created with the built-in image_gen tool on 2026-09-29; [exact prompts](prompts.json).

- [Pedestal sink](../../res/sprites/bathroom-sink.png)
- [Toilet](../../res/sprites/bathroom-toilet.png)
- [Toilet roll on spool stand](../../res/sprites/bathroom-roll-stand.png)

Each original transparent sheet contains five viewing angles, imported at 96x128 per frame. BathroomArt uses the regular directional sprite renderer, lighting and palette conversion. Hidden map props provide collision while the PNGs provide the visible fixtures. These are decorative fixtures without plumbing interactions; the mirror is not a live reflection.

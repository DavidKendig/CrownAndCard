# Stair, ceiling and courtyard asset set

SPDX-License-Identifier: CC-BY-NC-SA-4.0

Original Crown & Card art created with built-in image generation. The final prompts and the stair material revision are recorded in [prompts.json](prompts.json).

| Saved PNG | Applied to |
| --- | --- |
| [stair-marble.png](../../res/materials/stair-marble.png) | Grand staircase treads, risers and landing |
| [ceiling-coffer.png](../../res/materials/ceiling-coffer.png) | Mahogany and brass coffered ceilings |
| [courtyard-slate.png](../../res/materials/courtyard-slate.png) | Wet courtyard paths |
| [courtyard-gravel.png](../../res/materials/courtyard-gravel.png) | Courtyard ground |
| [courtyard-hedge.png](../../res/materials/courtyard-hedge.png) | Hedge geometry |
| [courtyard-iron.png](../../res/materials/courtyard-iron.png) | Fence posts, bars and rails |
| [tall-cedar.png](../../res/sprites/tall-cedar.png) | Layered tall cedar sprites |
| [tall-cypress.png](../../res/sprites/tall-cypress.png) | Slender tall cypress sprites |

The game quantizes the materials to its master palette and renders them with nearest filtering. Surface alpha is ignored; tree sprite alpha is preserved. No external image service is used at runtime.
